# Rstar-tree

This is a small library I made because I needed [r*-trees](https://dl.acm.org/doi/pdf/10.1145/93605.98741) for another project.
This library only contains the features I needed and is poorly optimized.
If you really plan to use r-trees, you should probably consider using a more serious crate such as [rstar](https://github.com/georust/rstar) or [rtree.rs](https://github.com/tidwall/rtree.rs).
